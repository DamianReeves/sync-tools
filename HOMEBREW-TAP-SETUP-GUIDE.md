# DamianReeves/homebrew-tap Setup Guide

This guide provides complete setup instructions for the `DamianReeves/homebrew-tap` repository to enable automated Homebrew formula updates via GoReleaser from the sync-tools project.

## Overview

This Homebrew tap provides macOS and Linux users with easy installation of DamianReeves projects via Homebrew. The tap is automatically maintained by GoReleaser when new releases are created in the main project repositories.

## Prerequisites

- GitHub account with admin access to `DamianReeves/homebrew-tap`
- Personal Access Token (PAT) with appropriate permissions
- GoReleaser integration configured in source projects (already completed for sync-tools)

## Step 2: GitHub Token Configuration

### 2.1 Create Personal Access Token

1. Go to GitHub Settings → Developer settings → Personal access tokens (classic)
2. Click "Generate new token (classic)"
3. Configure the token:
   - **Name**: `homebrew-tap-sync-tools`
   - **Expiration**: Set appropriate expiration (1 year recommended)
   - **Scopes**: Select these permissions:
     - ✅ `repo` (Full control of private repositories)
     - ✅ `workflow` (Update GitHub Action workflows) - optional but recommended

4. Generate and copy the token immediately (you won't see it again)

### 2.2 Add Token to sync-tools Repository

1. Go to the **sync-tools repository**: `https://github.com/DamianReeves/sync-tools`
2. Navigate to Settings → Secrets and variables → Actions
3. Click "New repository secret"
4. Configure the secret:
   - **Name**: `HOMEBREW_TAP_GITHUB_TOKEN`
   - **Value**: Paste your PAT from step 2.1
5. Click "Add secret"

⚠️ **Important**: The token must have write access to the `DamianReeves/homebrew-tap` repository.

## Step 3: GoReleaser Configuration Verification

The sync-tools repository already contains the required GoReleaser configuration. Verify these settings are present in `sync-tools/.goreleaser.yml`:

```yaml
brews:
  - name: sync-tools
    description: "Go CLI wrapper around rsync with advanced filtering and SyncFile post-sync actions"
    homepage: "https://github.com/DamianReeves/sync-tools"
    license: "Apache-2.0"
    
    repository:
      owner: DamianReeves
      name: homebrew-tap
      branch: main
      token: "{{ .Env.HOMEBREW_TAP_GITHUB_TOKEN }}"
    
    commit_author:
      name: "Damian Reeves"
      email: "damian@reevescodes.me"
    
    commit_msg_template: "Brew formula update for {{ .ProjectName }} version {{ .Tag }}"
    
    directory: Formula
    
    dependencies:
      - name: rsync
        type: runtime
    
    install: |
      bin.install "sync-tools"
      
      # Generate and install shell completions if available
      if File.exist?(buildpath/"completions")
        bash_completion.install "completions/sync-tools.bash" => "sync-tools"
        zsh_completion.install "completions/_sync-tools"
        fish_completion.install "completions/sync-tools.fish"
      end
    
    test: |
      assert_match version.to_s, shell_output("#{bin}/sync-tools --version 2>&1")
      assert_match "Advanced directory synchronization", shell_output("#{bin}/sync-tools --help")
      assert_match "sync", shell_output("#{bin}/sync-tools --help")
      assert_match "syncfile", shell_output("#{bin}/sync-tools --help")
```

## Troubleshooting

### Common Issues

**1. Formula not updating after release:**

- ✅ Check GitHub Actions logs in sync-tools repository
- ✅ Verify `HOMEBREW_TAP_GITHUB_TOKEN` secret exists and is valid
- ✅ Ensure token has `repo` permissions
- ✅ Check token hasn't expired

**2. Installation fails with checksum mismatch:**

```bash
# Clear Homebrew cache
brew cleanup sync-tools

# Try installation again
brew install DamianReeves/tap/sync-tools --verbose
```

**3. Permission denied during formula update:**

- ✅ Token must have write access to homebrew-tap repository
- ✅ Repository must be public (required for Homebrew taps)
- ✅ Check GitHub Actions runner permissions

**4. Formula syntax errors:**

```bash
# Audit the formula
brew audit --strict Formula/sync-tools.rb

# Test installation from formula
brew install --build-from-source ./Formula/sync-tools.rb
```

### Manual Formula Update (Emergency)

If automated updates fail, manually update the formula:

1. **Download latest release assets** from sync-tools
2. **Calculate checksums**:
   ```bash
   shasum -a 256 sync-tools_*_darwin_amd64.tar.gz
   shasum -a 256 sync-tools_*_linux_amd64.tar.gz
   ```
3. **Update Formula/sync-tools.rb** with new version and checksums
4. **Test the formula**:
   ```bash
   brew audit --strict Formula/sync-tools.rb
   brew install --build-from-source ./Formula/sync-tools.rb
   ```
5. **Commit and push** changes

### Debug Commands

# Verbose installation

## Security Considerations

1. **Token Security**:
   - Use tokens with minimal required permissions
   - Set reasonable expiration dates
   - Rotate tokens regularly

2. **Repository Access**:
   - Keep homebrew-tap repository public
   - Limit who has admin access
   - Monitor automated commits from GoReleaser

3. **Formula Validation**:
   - All formulas are automatically tested by GoReleaser
   - BDD tests must pass 100% before release
   - Checksums are automatically verified
