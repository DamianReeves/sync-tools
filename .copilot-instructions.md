## Quick Reference

sync-tools is a **Go CLI wrapper** around rsync that provides advanced directory synchronization with .syncignore files, whitelist mode, filter layering, one-way/two-way sync, conflict preservation, and SyncFile post-sync actions.

### Key Principles from CLAUDE.md
- **BDD/TDD Mandatory**: All features start with failing Gherkin scenarios (Red/Green/Refactor cycle)
- **Composition Over Inheritance**: Build flexible, reusable components
- **Testability First**: Design all components with testing as primary concern
- **Explicit Interfaces**: Value explicit, testable interfaces over implicit coupling
